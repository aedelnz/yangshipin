# 央视频 R [yangshipin]

央视频R是一款基于Android平台开发的电视直播应用，主要功能是通过WebView加载并播放央视频（yangshipin.cn）的频道直播。应用支持视频自动全屏播放、手机全屏显示等功能。

[![Latest release](https://img.shields.io/github/v/release/aedelnz/yangshipin?label=Release&logo=github)](https://github.com/aedelnz/yangshipin/releases)
[![GitHub License](https://img.shields.io/github/license/tiann/KernelSU?logo=gnu)](/LICENSE)

## 技术栈
- **开发语言**：Kotlin
- **开发框架**：Android SDK (API Level 22+)
- **构建工具**：Gradle
- **核心组件**：WebView

## 注意事项
- 建议使用Android 5.0+设备以获得最佳体验
